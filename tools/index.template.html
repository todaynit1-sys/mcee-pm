미세먼지 계절관리제

초미세먼지 농도가 높아지는 12월부터 이듬해 3월까지, 발전·수송·산업·생활 부문에서 평소보다 강화된 배출 저감·관리 조치를 시행하는 제도입니다

영상으로 보기체험형 콘텐츠

주제별 영상

      체험형 콘텐츠

      배출가스 5등급 차량 운행제한 단속, 비상저감조치 상황실, 고농도 시 대응요령을 3차원 마을에서 직접 체험할 수 있습니다

      체험형 콘텐츠 열기
      • 발표·교육‘새 창에서 보기’로 화면 전체에 띄웁니다
      • 소리배경음과 효과음은 ‘소리 켜기’를 누르면 나옵니다. 내용은 화면 자막으로 전달됩니다
      • 휴대폰‘휴대폰으로 읽기’는 장면 그림과 자막을 세로로 보여 줍니다
      기후에너지환경부 수도권대기환경청

      제8차 미세먼지 계절관리제(’26.12.1.~’27.3.31.) 안내용이며, 세부 시행 내용은 시행계획과 지역에 따라 달라질 수 있습니다

      실시간 대기질과 예보는 에어코리아, 세부 시행 내용은 관할 지방자치단체 안내를 확인하시기 바랍니다
